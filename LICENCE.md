## 🧩 About

**Gray Zone Warfare Menu** is a curated list of Gray Zone Warfare open-source tools:

- **Overlays** — on-screen helpers, layout notes, map viewer, loot tracker
- **Quality-of-Life Helpers** — inventory notes, loadout manager, HUD layout notes
- **Research Notes** — map layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Field Helpers
- Map Overlay — layered tactical map with labeled points of interest
- Loot Marker Notes — log and review container spots for study
- Threat overlay Notes — visualize nearby activity zones
- Movement Readout — speed and stance display for practice sessions

### 🎒 Loadout & Inventory
- Loadout Manager — save and compare gear presets
- Inventory Notes — organize ammo, meds, and task items
- Weight Tracker — review carry limits and stamina notes

### 🗺️ Map Layout
- Task Route Notes — segment study on any map layout
- Extraction Point Notes — record and review exit paths
- Waypoint Helper — chain navigation markers in the editor
